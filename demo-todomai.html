Todomai started as a minimal watchOS app for managing tasks with voice input. This iOS port keeps the menu screen an exact 1:1 copy: same three modes, same button colors, same sharp rectangles with thick black borders, no rounding. Switch modes above, then say or type a task and watch it route to a list, the same parsing the app runs on your words.

The project structure doc calls this an exact 1:1 port from watchOS: TodomaiApp.swift carries the shared Task, TaskList and ViewMode models, and the menu keeps the watch's rule of no corner radius and 6pt black borders on every button. The RADIO button on the menu traces back to a real commit, 4e8b3ba, "Add RADIO feature with music station downloads and player".

It isn't shipped. The Info.plist still has the placeholder bundle id $(PRODUCT_BUNDLE_IDENTIFIER), never filled in for a real build.
