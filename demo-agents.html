How I run the agents that build with me

Most of the work on this page was built with AI in the loop, every day, on a written system. This is that system, in real numbers from my machine.

3×/day
Unattended runs

A headless claude -p curriculum factory runs under launchd at 3am, 11am, 7pm and authors lessons on its own.

237
In the review queue

Everything the agent writes lands in factory/pending/. A human promotes it. The robot never writes to the live app.

53
Handoff documents

Every project has a HANDOFF / CLAUDE / PROJECT doc so a fresh agent window can pick it up cold.

111
Memory notes

A curated, file-based memory of laws, decisions and project state, maintained daily.

3
Custom agent skills

module-design, module-ship, watch, packaged multi-step workflows the agent invokes.

1
Command to say no

One-command gates (check.py, deploy.sh + tests) let the agent move fast because the gate refuses bad work.
