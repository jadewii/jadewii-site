 22  def check(path: pathlib.Path) -> dict:
 23      out = {"file": str(path), "size": path.stat().st_size}
 24      try:
 25          with open(path, "rb") as fh:
 26              raw = fh.read(8)
 27              if len(raw) < 8:
 28                  return {**out, "status": "error", "reason": "shorter than 8 bytes"}
 29              n = struct.unpack("<Q", raw)[0]
 30              if n > MAX_HEADER or 8 + n > out["size"]:
 31                  return {**out, "status": "error", "reason": f"header length {n} does not fit in file"}
 32              try:
 33                  hdr = json.loads(fh.read(n))
 34              except ValueError as e:
 35                  return {**out, "status": "error", "reason": f"header is not JSON: {e}"}
 36      except OSError as e:
 37          return {**out, "status": "error", "reason": str(e)}
 38  
 39      tensors = {k: v for k, v in hdr.items() if k != "__metadata__"}
 40      if not tensors:
 41          return {**out, "status": "error", "reason": "header lists no tensors"}
 42      try:
 43          end = max(v["data_offsets"][1] for v in tensors.values())
 44      except (KeyError, TypeError, IndexError):
 45          return {**out, "status": "error", "reason": "tensor entry missing data_offsets"}
 46  
 47      expected = 8 + n + end
 48      delta = out["size"] - expected
 49      status = "ok" if delta == 0 else ("truncated" if delta < 0 else "trailing")
 50      dtypes = sorted({v.get("dtype", "?") for v in tensors.values()})
 51      return {**out, "status": status, "expected": expected, "delta": delta,
 52              "tensors": len(tensors), "dtypes": dtypes}




A safetensors file is an 8-byte little-endian header length, a JSON header that lists every tensor with its byte offsets, then the tensor bytes. So the correct file size is fully determined by the header. The tool reads the header, computes the expected length and compares. Delta zero is valid, negative is a truncated download, positive is trailing data the header does not cover.

I wrote it after InvokeAI failed a generation with incomplete metadata, file not fully covered and named the checkpoint. The checkpoint was fine: size and sha256 matched Civitai, 2,515 tensors, it opened cleanly. The corrupt file was a LoRA loaded in the same graph. The loader reports the error against whichever file it was busy with, so the rule became: never trust the filename in that error, check every file.


The sweep of my library found two bad files out of 102. One LoRA was truncated by 25.9 MB, an interrupted download. Another had 43 MB of trailing data the header did not cover, byte-identical to its Hugging Face mirror, so it was broken upstream and the Civitai copy was clean. The exit code is 0 only when every file passes, which lets it sit in a download script or a cron job as a gate.
