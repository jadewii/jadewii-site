safetensors-check

Python · CLI · model file validation

A 100-line tool that answers one question: is this model file exactly as long as its header says it is?

The problem

I run a local image generation pipeline on top of InvokeAI with 1,300+ checkpoints and LoRAs. One day a generation failed with:

Error while deserializing header: incomplete metadata, file not fully covered

The error named the checkpoint. The checkpoint was fine: size and sha256 matched Civitai, 2,515 tensors, it opened cleanly. The actually corrupt file was a LoRA loaded in the same graph. The loader reports the error against whichever file it was busy with, not the one that is broken.

So the rule became: never trust the filename in that error. Check every file.

How it works

A .safetensors file has three parts:

  1. 8 bytes: the header length, little-endian.
  2. The header: JSON that lists every tensor with its data_offsets.
  3. The tensor bytes.

That means the correct file size is fully determined by the header:

expected = 8 + header_length + max(data_offsets end)
delta    = actual_size - expected
  • delta == 0: valid.
  • delta < 0: truncated. The download stopped early. Re-fetch.
  • delta > 0: trailing bytes the header does not cover. In practice this has meant the file was broken at the source, not in transit. Compare against the remote content-length before re-downloading.

Usage

python3 check.py ~/invokeai/models            # recursive
python3 check.py --only-bad ~/invokeai/models
python3 check.py --json some_lora.safetensors

Exit code is 0 only if every file passed, so it drops into a download script or a cron job as a gate.

#!/usr/bin/env python3
"""safetensors-check: is this model file exactly as long as its header says it is?

A .safetensors file is: 8-byte little-endian header length, a JSON header that
lists every tensor with its byte offsets, then the raw tensor bytes. So the
file size is fully determined by the header. If the real size differs, the
file is truncated (bad download) or has uncovered trailing data (broken at the
source). Loaders report these as vague deserialization errors, and InvokeAI in
particular blames whichever file it was loading in the same graph, which is
often the wrong one. This checks every file directly.

Usage:
    python3 check.py PATH [PATH ...]      # files or directories (recursive)
    python3 check.py --json PATH          # machine-readable
Exit code is 0 only if every file checked out.
"""
import argparse, json, pathlib, struct, sys

MAX_HEADER = 256 * 1024 * 1024  # anything bigger than 256MB is not a real header


def check(path: pathlib.Path) -> dict:
    out = {"file": str(path), "size": path.stat().st_size}
    try:
        with open(path, "rb") as fh:
            raw = fh.read(8)
            if len(raw) < 8:
                return {**out, "status": "error", "reason": "shorter than 8 bytes"}
            n = struct.unpack("<Q", raw)[0]
            if n > MAX_HEADER or 8 + n > out["size"]:
                return {**out, "status": "error", "reason": f"header length {n} does not fit in file"}
            try:
                hdr = json.loads(fh.read(n))
            except ValueError as e:
                return {**out, "status": "error", "reason": f"header is not JSON: {e}"}
    except OSError as e:
        return {**out, "status": "error", "reason": str(e)}

    tensors = {k: v for k, v in hdr.items() if k != "__metadata__"}
    if not tensors:
        return {**out, "status": "error", "reason": "header lists no tensors"}
    try:
        end = max(v["data_offsets"][1] for v in tensors.values())
    except (KeyError, TypeError, IndexError):
        return {**out, "status": "error", "reason": "tensor entry missing data_offsets"}

    expected = 8 + n + end
    delta = out["size"] - expected
    status = "ok" if delta == 0 else ("truncated" if delta < 0 else "trailing")
    dtypes = sorted({v.get("dtype", "?") for v in tensors.values()})
    return {**out, "status": status, "expected": expected, "delta": delta,
            "tensors": len(tensors), "dtypes": dtypes}


def walk(paths):
    for p in paths:
        p = pathlib.Path(p).expanduser()
        if p.is_dir():
            yield from sorted(q for q in p.rglob("*.safetensors") if q.is_file())
        elif p.is_file():
            yield p
        else:
            print(f"skip (not found): {p}", file=sys.stderr)


def human(n):
    for unit in ("B", "KB", "MB", "GB"):
        if abs(n) < 1024 or unit == "GB":
            return f"{n:.1f}{unit}" if unit != "B" else f"{n}B"
        n /= 1024


def main(argv=None):
    ap = argparse.ArgumentParser(description=__doc__.split("\n")[0])
    ap.add_argument("paths", nargs="+")
    ap.add_argument("--json", action="store_true", help="print one JSON object per line")
    ap.add_argument("--only-bad", action="store_true", help="hide files that pass")
    args = ap.parse_args(argv)

    results = [check(p) for p in walk(args.paths)]
    bad = [r for r in results if r["status"] != "ok"]

    if args.json:
        for r in results:
            if args.only_bad and r["status"] == "ok":
                continue
            print(json.dumps(r))
    else:
        for r in results:
            if args.only_bad and r["status"] == "ok":
                continue
            name = pathlib.Path(r["file"]).name
            if r["status"] == "ok":
                print(f"  ok         {name}  ({r['tensors']} tensors, {', '.join(r['dtypes'])})")
            elif r["status"] == "error":
                print(f"  ERROR      {name}  {r['reason']}")
            else:
                print(f"  {r['status'].upper():<10} {name}  delta {human(r['delta'])}")
        print(f"\n{len(results)} checked, {len(bad)} bad")
    return 1 if bad else 0


if __name__ == "__main__":
    sys.exit(main())
