Web Audio · one chain factory · knobs, faders and a scope · three of my tracks below, press play and turn it

manglerChain.js · 25 keys

Every knob here writes to a live AudioParam through one function, setParam, with a short ramp so nothing clicks. The chain is a factory: the popup player, the studio and the hardware page each build their own copy on their own AudioContext, because Web Audio nodes cannot cross contexts.

The details are where the product lives. Hiss sits on a fourth-power curve with a low ceiling, because the comment in the code quotes me: hiss at 100 is too much. Delay time ramps over 400 ms because a hard set clicks on browser DelayNodes. Stop is a 300 ms fade, not a cut, so release tails ring out the way they do in the studio. The same unit is being ported to an iPhone app that loads as an AUv3 effect in AUM and GarageBand, with the DSP in Cmajor.

This is the shape I use whenever a new capability has to land inside a real product, a model included: one place it lives, a named set of inputs with ranges, a gate on who gets it, and rules for how it starts and stops. The mangler taught me those rules on sound first.
