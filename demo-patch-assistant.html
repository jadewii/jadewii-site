Patch assistant for Eurorack Grid

Python · Claude API tool use · deterministic validator · tests

Describe a sound. Get back a modular synth patch that has been checked, not just written.

Eurorack Grid is my browser-based modular synth: 87 module brands generated from 71 module archetypes, each with real jacks that carry pitch, gate, CV, or audio. A patch is a list of modules and the cables between them. It is easy for a language model to write a patch that looks right and does nothing: a cable into an input that does not exist, audio into a pitch input, two cables fighting over one jack, nothing reaching the output.

The design

The model never gets to declare its own patch valid. It has three tools:

  • list_modules(role): the catalog, by role (osc, filter, env, seq, drum, fx, ...).
  • describe_module(archetype): the exact jacks on one module, with direction and signal kind.
  • validate_patch(patch_json): a deterministic Python checker. It returns valid: true or a list of specific errors.

The system prompt says: you may not answer until the validator says yes. The Anthropic SDK's tool runner drives the loop. When the validator accepts a patch, it stores that patch. The CLI saves the stored patch, not whatever the model wrote in prose. So the file on disk is always one the checker passed.

validate.py has no API dependency and its own test suite (test_validate.py, 10 cases: unknown module, input wired to input, audio into a pitch jack, two cables on one input, rack over its HP limit, nothing reaching OUT, and so on).

Why this shape

This is the pattern behind most useful agent work: the model proposes, a boring piece of code disposes. The interesting engineering is in the validator and the tool descriptions, not the prompt. Every error message is written to tell the model what to do next, because the model is the one reading it.

It is also honest about what the model is good at. It is good at "an acid line needs a sequencer, a squelchy voice, and a filter with the cutoff modulated." It is bad at remembering that this particular filter's cutoff jack is called cut, not cutoff. The tool split puts each job where it belongs.

Run

uv venv .venv && uv pip install --python .venv/bin/python anthropic
export ANTHROPIC_API_KEY=...
.venv/bin/python assistant.py -v "slow drone with a filter that breathes" --save patches/drone.json
python3 test_validate.py     # offline

-v prints every tool call so you can watch the model get told no and fix it.

Limits

  • The catalog is a snapshot of the archetype table, not the live app. 19 archetypes share jack arrays defined elsewhere in the app; for those I filled in the jacks by role, and the file marks them jacks_inferred.
  • The validator checks wiring, not sound. A valid patch can still be boring.
  • Loading a saved patch into the app is not wired up yet. That is the next step, and it is a JSON import, not a model problem.

"""Patch validator for Eurorack Grid archetypes. Pure Python, no API. This is the tool that says no."""
import json, pathlib

CATALOG = json.load(open(pathlib.Path(__file__).with_name("catalog.json")))
ARCH, BRANDS = CATALOG["archetypes"], set(CATALOG["brands"])

# what kind of output may feed what kind of input
COMPAT = {("audio", "audio"), ("audio", "cv"), ("cv", "cv"), ("cv", "pitch"), ("cv", "audio"),
          ("pitch", "pitch"), ("pitch", "cv"), ("gate", "gate"), ("gate", "cv")}


def validate(patch: dict, hp_limit: int = 104) -> dict:
    errors, warnings = [], []
    mods = patch.get("modules") or []
    cables = patch.get("cables") or []
    if not isinstance(mods, list) or not mods:
        return {"valid": False, "errors": ["patch has no modules"], "warnings": [], "hp_used": 0}

    slots = {}
    for m in mods:
        slot, arch, brand = m.get("slot"), m.get("archetype"), m.get("brand")
        if not slot or not isinstance(slot, str):
            errors.append(f"module missing a slot name: {m}"); continue
        if slot in slots:
            errors.append(f"duplicate slot name '{slot}'"); continue
        if arch not in ARCH:
            errors.append(f"slot '{slot}': unknown archetype '{arch}' (use list_modules)"); continue
        if arch != "OUT" and brand not in BRANDS:
            errors.append(f"slot '{slot}': unknown brand '{brand}'")
        slots[slot] = ARCH[arch]

    hp_used = sum(a["hp"] for a in slots.values())
    if hp_used > hp_limit:
        errors.append(f"rack is {hp_used}HP, limit is {hp_limit}HP; drop or shrink something")
    outs = [s for s, a in slots.items() if a["role"] == "out"]
    if len(outs) != 1:
        errors.append(f"patch needs exactly one OUT module, found {len(outs)}")

    def jack(ref):
        if not isinstance(ref, str) or "." not in ref:
            return None, None, f"bad jack reference '{ref}', want slot.jack"
        slot, jid = ref.split(".", 1)
        if slot not in slots:
            return None, None, f"'{ref}': no slot named '{slot}'"
        for j in slots[slot]["jacks"]:
            if j["id"] == jid:
                return slot, j, None
        have = ", ".join(j["id"] for j in slots[slot]["jacks"])
        return slot, None, f"'{ref}': slot '{slot}' has no jack '{jid}' (has: {have})"

    fed = {}
    for c in cables:
        fs, fj, e1 = jack(c.get("from")); ts, tj, e2 = jack(c.get("to"))
        if e1: errors.append(e1)
        if e2: errors.append(e2)
        if e1 or e2 or fj is None or tj is None:
            continue
        if fj["dir"] != "out":
            errors.append(f"{c['from']} is an input, cables must start at an output")
        if tj["dir"] != "in":
            errors.append(f"{c['to']} is an output, cables must end at an input")
        if fj["dir"] == "out" and tj["dir"] == "in" and (fj["kind"], tj["kind"]) not in COMPAT:
            errors.append(f"{c['from']} ({fj['kind']}) into {c['to']} ({tj['kind']}) will not do anything useful")
        if c["to"] in fed:
            errors.append(f"{c['to']} already has a cable from {fed[c['to']]}; one cable per input")
        fed[c["to"]] = c["from"]

    if outs:
        o = outs[0]
        if not any(k.startswith(o + ".") for k in fed):
            errors.append("nothing is patched into OUT; you will hear silence")
    for s, a in slots.items():
        if a["role"] in ("osc", "voice", "drum", "noise", "fx", "filter", "vca", "mix"):
            has_out = any(j["dir"] == "out" for j in a["jacks"])
            used = any(f.startswith(s + ".") for f in fed.values())
            if has_out and not used and a["role"] != "out":
                warnings.append(f"slot '{s}' ({a['role']}) has no cable leaving it; it is silent")
        if a["role"] in ("voice", "drum") and not any(k.startswith(s + ".") for k in fed):
            warnings.append(f"slot '{s}' ({a['role']}) has no gate or trigger coming in; it will never fire")

    return {"valid": not errors, "errors": errors, "warnings": warnings, "hp_used": hp_used}

#!/usr/bin/env python3
"""Patch assistant for Eurorack Grid: describe a sound, get a patch that actually validates.

The model does not get to hand back a patch it made up. It has three tools: list
the module catalog, describe one module's jacks, and validate a patch. The
validator is deterministic Python (validate.py) and it is the only thing that
gets to say "valid". The loop runs until the validator says yes or the model
gives up and explains why.

    python3 assistant.py "a slow evolving drone with a filter that breathes"
    python3 assistant.py --hp 84 "acid line, 303 style, with delay" --save patches/acid.json

Needs ANTHROPIC_API_KEY (or an `ant auth login` profile).
"""
import argparse, json, pathlib, sys
import anthropic
from anthropic import beta_tool
from validate import ARCH, BRANDS, validate

MODEL = "claude-opus-5"
LAST_VALID = {}   # the validator stores the last patch it accepted; the CLI saves that, not model prose
HP_LIMIT = 104


@beta_tool
def list_modules(role: str = "") -> str:
    """List available module archetypes with their role and size in HP.

    Args:
        role: Filter by role. One of osc, voice, filter, env, lfo, vca, mix, fx, seq, drum, noise, util, out. Empty string lists everything.
    """
    rows = [f"{k}  role={v['role']}  {v['hp']}HP" for k, v in ARCH.items() if not role or v["role"] == role]
    return "\n".join(rows) or f"no archetypes with role '{role}'"


@beta_tool
def describe_module(archetype: str) -> str:
    """Show the jacks (inputs and outputs, with signal kind) of one archetype.

    Args:
        archetype: The archetype id from list_modules, e.g. osc_fm.
    """
    a = ARCH.get(archetype)
    if not a:
        return f"unknown archetype '{archetype}'"
    jacks = "\n".join(f"  {j['dir']:<3} {j['id']:<8} {j['kind']:<6} {j['label']}" for j in a["jacks"])
    return f"{archetype}: role={a['role']} {a['hp']}HP\n{jacks}"


@beta_tool
def validate_patch(patch_json: str) -> str:
    """Validate a patch. Returns valid:true or a list of concrete errors to fix. Call this before answering.

    Args:
        patch_json: JSON with "modules": [{"slot": "vco1", "archetype": "osc_fm", "brand": "abyss"}, ...], "cables": [{"from": "vco1.out", "to": "out.l"}, ...], and "notes": short text on what each knob should do. Exactly one module must use archetype "OUT".
    """
    try:
        patch = json.loads(patch_json)
    except ValueError as e:
        return json.dumps({"valid": False, "errors": [f"not valid JSON: {e}"]})
    result = validate(patch, HP_LIMIT)
    if result["valid"]:
        LAST_VALID.clear(); LAST_VALID.update(patch)
    return json.dumps(result)


SYSTEM = """You design patches for Eurorack Grid, a browser modular synth. The user describes a sound.
Rules:
- Use only archetypes from list_modules and only jacks from describe_module. Do not guess jack names.
- Brands are cosmetic; pick any from this list and vary them: {brands}.
- The rack is {hp}HP. Always include exactly one module with archetype OUT.
- You must call validate_patch and get valid:true before you answer. Fix every error it reports. Warnings are advice; fix them if they matter for the sound.
- Final answer: a short patch sheet in plain words: what each module does, the cable list, and three knob settings that matter. No JSON in the answer; the validated patch is captured separately."""


def run(prompt: str, hp: int, verbose: bool) -> tuple[str, dict]:
    global HP_LIMIT
    HP_LIMIT = hp
    client = anthropic.Anthropic()
    runner = client.beta.messages.tool_runner(
        model=MODEL,
        max_tokens=16000,
        system=SYSTEM.format(brands=", ".join(sorted(BRANDS)[:12]), hp=hp),
        tools=[list_modules, describe_module, validate_patch],
        messages=[{"role": "user", "content": prompt}],
    )
    last = None
    for message in runner:
        last = message
        if verbose:
            for b in message.content:
                if b.type == "tool_use":
                    print(f"  -> {b.name}({json.dumps(b.input)[:120]})", file=sys.stderr)
    text = "\n".join(b.text for b in last.content if b.type == "text") if last else ""
    return text, dict(LAST_VALID)


def main(argv=None):
    ap = argparse.ArgumentParser(description=__doc__.split("\n")[0])
    ap.add_argument("prompt")
    ap.add_argument("--hp", type=int, default=104)
    ap.add_argument("--save", help="write the validated patch JSON here")
    ap.add_argument("-v", "--verbose", action="store_true", help="show tool calls")
    args = ap.parse_args(argv)
    text, patch = run(args.prompt, args.hp, args.verbose)
    print(text)
    if not patch:
        print("\n[no patch passed validation]", file=sys.stderr)
        return 1
    if args.save:
        p = pathlib.Path(args.save); p.parent.mkdir(parents=True, exist_ok=True)
        p.write_text(json.dumps(patch, indent=2))
        print(f"\nsaved {p}", file=sys.stderr)
    return 0


if __name__ == "__main__":
    sys.exit(main())
